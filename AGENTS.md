# AmbientBGM Mobile

A Capacitor 8 app (iOS / Android) that does nothing more than open ambientbgm.com in a WebView.
`server.url` in `capacitor.config.json` loads the production site directly, so `www/` is only
the page shown while loading. This is a public repository, so the README and this file are written in English.

It originally lived in `mobileapp/` of `cyberneura/ambientbgm` (split out in CYBERNEURA-DEV-859).
The web player itself lives in that repository.

## Steps

```shell
pnpm install
pnpm exec cap sync      # apply capacitor.config.json to ios/ and android/
pnpm exec cap open ios
```

- `ios/App/App/capacitor.config.json` and `android/app/src/main/assets/capacitor.config.json`
  are generated by `cap sync` (already gitignored). Edit the root `capacitor.config.json` to change settings
- iOS dependencies use Swift Package Manager (`ios/App/CapApp-SPM`). CocoaPods is not used
- **iOS / Android builds cannot be done on this host (Linux).** Up to `cap sync` works
- The version lives in `MARKETING_VERSION` / `CURRENT_PROJECT_VERSION` in `project.pbxproj` for iOS,
  and in `versionName` / `versionCode` in `android/app/build.gradle` for Android

## How the chat UI is hidden

`appendUserAgent: "AmbientBGMApp"` appends a token to the User-Agent.
ambientbgm.com (`chatVisibility.ts` in the webapp) hides the chat widget when this token is present.
If you change the token name, keep it in sync with the webapp.
